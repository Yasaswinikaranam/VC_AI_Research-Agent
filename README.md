# VC AI Research Agent

AI-powered venture capital research and investment analysis platform.

## 🚀 Live Demo

*https://vcairesearch-agent-qpffpwofve6uohheur2jnd.streamlit.app/**

## What it does

Researches early-stage companies and generates structured investment analysis using:

- Company & market research
- TAM / SAM / SOM
- Competitive landscape
- Competitive moat
- Traction
- Team analysis
- Risk assessment
- Investment thesis
- Weighted investment score

## Tech Stack

- Python
- Streamlit
- Anthropic Claude API
- Tavily API
